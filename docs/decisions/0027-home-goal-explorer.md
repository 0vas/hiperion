# Six goals on the home page

Status: accepted.

The home expands beyond documentation, installation and code review into six goals: build, research, create, analyze, operate and coordinate. Each has a localized copyable request, an illustrative plan, a human decision and the capabilities needed to execute it. Existing quickstart examples remain available.

The explorer keeps one case visible at a time. Decisions are local sample data, reset on category changes and never trigger tools, persist user responses or call a runtime. Planned steps carry roles rather than invented execution states. Connector and delegation requirements remain explicit.

Acceptance criteria: six distinct bilingual prompts, keyboard-operable decisions, truthful simulation labels, isolation between cases, working clipboard and reset, no mobile overflow and accessible colors in both themes. Add a failing browser test first, validate the full docs suite and project checks, and inspect the home at desktop and phone sizes before publishing.
