# Hyperion identity

The current mark is `hyperion-app.png`: a generated icon with two ribbons of solar light and a path between them. The same asset identifies the website, favicon, product illustration and README. Use it with the Hyperion wordmark, preserve its proportions and keep clear space around it.

[Generation method and exact prompt](./generation.md). The PNG is the actual generated asset, not a hand-drawn substitute. UI and platform symbols remain local SVGs. Previously published SVG marks are retained as historical studies and are no longer used by the website. Existing installer binaries are unchanged.

Colors: midnight, amber and warm gold. The dark icon tile keeps the mark distinct in both light and dark themes. Platform symbols identify compatible systems and do not imply endorsement.
