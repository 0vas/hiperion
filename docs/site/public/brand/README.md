# Hyperion identity

Original vector artwork for this repository, under its MIT license. Inspired by Hyperion's association with light: a rising solar arc, a horizon and one short line of reflected light. It does not trace, embed or reproduce the supplied stock illustration.

- `../logo.svg`: minimal solar symbol and documentation favicon.
- `hyperion-solar.svg`: transparent home-page illustration.
- `hyperion-banner.svg`: README lockup on a midnight background.

Palette: midnight `#17252b`, solar gold `#b88a43`, ivory `#f7f3e9`. Keep clear space around the symbol and use descriptive alternative text. These documentation assets do not change the icons inside already released installers.
