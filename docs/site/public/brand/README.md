# Hyperion identity

The current mark is `hyperion-titan.png`: a generated geometric solar titan with a three-part crown and an angular visage. The same asset identifies the website, favicon, product illustration and README. Use it with the Hyperion wordmark, preserve its proportions and keep clear space around it.

[Generation method and exact prompt](./generation-titan.md). The PNG is the actual generated asset, not a hand-drawn substitute. UI and platform symbols remain local SVGs. The former ribbon (`hyperion-app.png`) and previously published SVG marks are retained as historical studies and are no longer used by the website. Existing installer binaries are unchanged.

Colors: midnight, amber and warm gold. The dark icon tile keeps the mark distinct in both light and dark themes. Platform symbols identify compatible systems and do not imply endorsement.
